# Практическая работа №02: Инвентарь героя

* **Вариант:** А · Воин (лимит массы 6000 г, 4 ячейки)
* **Среда разработки:** JDK 21, Maven 3.9+, VS Code
* **Пакет проекта:** `kz.javaworkshop`

---

## 1. Структура классов и разделение ответственности

* **Модель данных (бизнес-логика):**
  * `kz.javaworkshop.Item` — неизменяемый предмет (Immutable). Гарантирует инварианты полей (длина имени от 1 до 40 символов, типы `weapon`/`armor`/`potion`, диапазоны массы и стоимости).
  * `kz.javaworkshop.Inventory` — модель инвентаря. Ограничивает число ячеек (до 4) и общую массу (до 6000 г). Динамически вычисляет массу без дублирования состояния в отдельном поле. При удалении сдвигает элементы влево.
* **Консольный интерфейс (UI):**
  * `kz.javaworkshop.Main` — осуществляет считывание пользовательского ввода через `Scanner` и отображение консольного меню. Обращается к модели только через ее публичные методы.

3. Результаты проверок контрольных сценариев
Сценарий 1. Заполнение до точного лимита

    Действие: Добавлены три начальных предмета:

        Меч [weapon], 2500 г, 100 монет

        Щит [armor], 3000 г, 80 монет

        Зелье [potion], 500 г, 20 монет

    Результат: Занято ячеек: 3/4, общая масса: 6000/6000 г, стоимость: 200 монет. Лимит массы заблокирован на 100%.

Сценарий 2. Отказ при превышении лимита массы

    Действие: Попытка добавить предмет "Орешки" (20 г) в рюкзак, где свободна 1 ячейка, но масса равна 6000/6000 г.

    Результат: Системный отказ: "Отклонено: нет места или превышен лимит массы". Состояние рюкзака не изменилось.

Сценарий 3. Проверка типов при использовании зелья

    Действие: Попытка использовать предмет №1 ("Меч", тип weapon).

    Результат: Сообщение "Предмет не является зельем! Ничего не изменено.". Предмет остался в инвентаре.

    Действие: Попытка использовать предмет №3 ("Зелье", тип potion).

    Результат: Вывод "Зелье использовано". Предмет удален, ячейки сдвинуты влево, занято 2/4 ячеек, масса снизилась до 5500 г.

Сценарий 4. Защита состояния (независимость snapshot)

    Проверка: Метод snapshot() возвращает копию массива Item[]. Изменение или зануление элементов полученного массива вне класса Inventory не влияет на реальное содержимое рюкзака.
